# Pakistan Driving License Quiz - Improved Web Application

## Overview
This is an enhanced web-based driving license quiz application specifically designed for Pakistani traffic rules and regulations. It provides an interactive and user-friendly platform for practicing driving theory tests.

## Features

### **Interactive Quiz System**
- 20 comprehensive questions based on Pakistani traffic laws
- Multiple choice questions with immediate feedback
- Progress tracking with visual progress bar
- 15-minute time limit with countdown timer
- Keyboard navigation support (arrow keys, number keys)

### **Responsive Design**
- Mobile-friendly interface that works on all devices
- Modern, clean design with smooth animations
- Accessible color scheme and typography
- Touch-friendly buttons and interface elements

### **Results & Analytics**
- Detailed score breakdown with percentage
- Pass/fail indication (70% required to pass)
- Time taken tracking
- Answer review with explanations
- Grade classification (Excellent, Good, Poor)

### **Study Guide**
- Comprehensive study materials
- Organized topics: Road Signs, Traffic Rules, Safety Rules
- Visual learning aids with icons
- Pakistani-specific traffic regulations

### **User Experience**
- Intuitive navigation between sections
- Visual feedback for selected answers
- Prevent accidental page refresh during quiz
- Smooth transitions and hover effects

## How to Use

### **Starting the Application**
1. Open `index.html` in any modern web browser
2. Navigate using the header buttons or start directly with "Start Quiz Now"

### **Taking the Quiz**
1. Click "Start Quiz" to begin the 15-minute timer
2. Read each question carefully
3. Click on your chosen answer (it will highlight)
4. Use "Next" and "Previous" buttons to navigate
5. Submit when ready or when time expires

### **Keyboard Shortcuts**
- **Arrow Left**: Previous question
- **Arrow Right**: Next question
- **1, 2, 3, 4**: Select answer options

### **Reviewing Results**
- View your score percentage and grade
- Check detailed statistics
- Review all answers with explanations
- Retake the quiz to improve your score
